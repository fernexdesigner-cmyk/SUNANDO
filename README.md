# SUNANDO

App para Windows que monta prompts, letras, arranjos e capas para o Suno v6.

- **Baixar:** veja a versão mais recente em [Releases](../../releases/latest).
- **Atualização automática:** o app instalado verifica este repositório ao abrir e a cada 4 horas.
- **Conhecimento do Suno:** `knowledge/suno-pack.json` traz modelos, tags e técnicas. O app baixa esse pacote sozinho, então dá para ensinar novidades do Suno (por exemplo, um v7) sem gerar um instalador novo.
- **Monitor:** a ação "Monitorar novidades do Suno" lê as páginas oficiais do Suno a cada 6 horas, grava o que encontrou em `knowledge/suno-feed.json` e abre um aviso quando aparece uma versão nova.

SUNANDO é uma ferramenta independente, sem vínculo com a Suno, Inc.
